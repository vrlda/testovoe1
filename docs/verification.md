# Проверка первой версии

- Чистая установка через `npm ci`, TypeScript и production-сборка.
- Автоматические проверки: фиксация версии и варианта, публикация и rollback, уникальность событий, изоляция ошибок пачки, валидация, HTTP, TTL и сохранение очереди при сетевых ошибках.
- Генератор на отдельной локальной базе: 120 сессий, 60 A / 60 B, по 30 сессий в четырёх кампаниях, 47 результатов и 29 сессий с кликом. 951 принятое событие просмотра/CTA и 280 ответов о дубле.
- Метрики 16 шагов двух вариантов сверены с независимыми SQL-запросами.
- Браузер: прохождение до рекомендации, валидация, Back, refresh, восстановление черновиков и повторное открытие, восстановление после ошибки сети, фильтр кампании, управление распределением и публикацией.
- Русский интерфейс проверен на ширине 320, 390 и 1440 пикселей. Широкие таблицы прокручиваются внутри страницы.
- Исходный `workstyle-v1.json` сохранён без изменений. Генератор не запускается автоматически и не использовался для заполнения публичной базы.

## Проверка защиты API

Регрессии покрывают обязательный токен, ограничения UTM по байтам (включая Unicode и старые строки базы), размер пачки, лимит событий сессии, дедупликацию на лимите, ограничение частоты запросов, поддельный `X-Forwarded-For` и повтор очереди после `429`.

Локально в браузере проверены: ссылка с дублированным/кодированным `session` не подменяет сессию; старые проверочные ключи не принимаются; параметры кампании и fragment сохраняются; refresh восстанавливает сессию и черновик; перезапуск создаёт новую сессию; варианты A/B остаются раздельными.
